🎯 Number Guessing Game (Python)
🧩 Overview

This is a simple command-line number guessing game written in Python.
The program randomly selects a number between 1 and 100, and the player has 7 attempts to guess it correctly.
After each guess, the game provides hints — whether the guess is too high or too low.

🚀 Features

Random number generation between 1 and 100

Maximum of 7 attempts per game

Input validation for non-numeric entries

Instant feedback after every guess

Reveals the correct number after attempts are over

🧠 How It Works

The computer randomly picks a number between 1 and 100.

The player tries to guess the number within 7 attempts.

For each guess:

If the guess is correct → 🎉 “Correct you guessed it...”

If the guess is lower → 📉 “Too low!”

If the guess is higher → 📈 “Too high!”

If all 7 attempts are used, the program displays the correct number.
